## 三、提交前自检

```bash
python -m unittest discover -s tests -v      # 76 个用例，应全过
python evals/calibrate.py                    # 阈值标定，不需要密钥
python tools/demo_offline.py                 # 端到端主链路，需要先抓两版演示论文
python tools/mock_server.py --port 8010      # 无依赖看界面（评审机器没装环境时用这个演示）
```

录屏前建议真后端起一次：`python run.py`，浏览器打开 http://127.0.0.1:8000/ 。

## 四、密钥安全（会被检查）

- 所有密钥只从环境变量读取，唯一读取点是 `zhiwei/config.py`。
- `.env` 已在 `.gitignore` 中；仓库内不含任何真实密钥（可 `git log -p | findstr sk-` 自证）。
- `GET /api/health` 只返回密钥后四位。
- 录屏时不要打开 `.env`，也不要让终端历史里的密钥入镜。
