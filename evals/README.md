# 闸门阈值标定

`golden.jsonl` 是手工标注的评测集，36 条，三类各 12 条：

| 标签 | 含义 | 典型构造方式 |
| --- | --- | --- |
| `allow` | 应当放行 | 数字/术语与原文一致，或近乎逐字复述 |
| `downgrade` | 应当降级为「待核实」 | 跨语言、概括过宽、把「可能」写成「已证明」 |
| `block` | 应当拦下 | 没有出处、引文编造、数字与原文冲突 |

每条都带 `in_source` 标记：`false` 表示这条引文**故意不在**原文里，用来测「引文定位」这道硬检查。

跑：

```bash
python evals/calibrate.py                # 离线词法裁判（不需要 key）
python evals/calibrate.py --judge llm    # 用模型裁判复核
```

输出一份 `evals/report.md`：阈值网格上的三分类 P/R/F1、拦下召回率，以及与默认阈值
（拦下 0.35 / 放行 0.75）的对比。
